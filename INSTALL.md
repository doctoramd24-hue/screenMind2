# 🛠 Инструкция по установке и запуску ScreenMind2 Ultra

ScreenMind2 Ultra — это локальная база знаний с интеграцией ИИ. Все данные хранятся в браузере (IndexedDB), а для работы ИИ используются внешние или локальные API.

## 1. Требования
- **Node.js**: v18 или выше.
- **NPM**: v9 или выше.
- **Браузер**: Chrome, Edge или Safari (с поддержкой IndexedDB и Web Audio API).

## 2. Установка
1.  **Склонируйте проект**:
    ```bash
    git clone <url_репозитория>
    cd screenmind2
    ```
2.  **Установите зависимости**:
    ```bash
    npm install
    ```

## 3. Запуск
1.  **Режим разработки**:
    ```bash
    npm run dev
    ```
    Приложение будет доступно по адресу `http://localhost:3000` (или другом порту, указанном в консоли).

2.  **Сборка для продакшена**:
    ```bash
    npm run build
    ```
    Статические файлы будут созданы в папке `dist/`.

## 4. Настройка ИИ (Критически важно)
После запуска перейдите в раздел **Настройки** (иконка шестеренки в сайдбаре).

### Провайдеры:
- **Gemini (Рекомендуется)**: Получите ключ на [Google AI Studio](https://aistudio.google.com/). Вставьте его в поле API Key.
- **Ollama (Локально)**: Установите [Ollama](https://ollama.com/), запустите модель (например, `ollama run mistral`). В настройках укажите URL `http://localhost:11434`.
- **LM Studio**: Запустите локальный сервер в LM Studio и укажите URL `http://localhost:1234/v1`.

## 5. Подключение Telegram
1.  Создайте бота через `@BotFather`.
2.  Получите **Token**.
3.  Узнайте свой **Chat ID** (через `@userinfobot`).
4.  Введите данные в настройках ScreenMind.
5.  Нажмите "Синхронизировать" на странице Telegram в приложении.

## 6. Использование PWA
Приложение поддерживает режим PWA. Вы можете "установить" его как отдельное приложение на рабочий стол ПК или главный экран телефона через меню браузера.

# 📖 Техническая документация ScreenMind2 Ultra

## 1. Архитектурная логика
Приложение построено на принципе **Local-First**. Это означает, что:
- Все заметки, цели и настройки хранятся в браузере пользователя через `IndexedDB` (библиотека `idb-keyval`).
- Приложение работает оффлайн (через Service Workers / PWA).
- ИИ-запросы отправляются напрямую с клиента на API провайдеров (или через прокси для локальных моделей).

## 2. Структура данных (Types)
Основные сущности описаны в `types.ts`:
- `Note`: Объект заметки. Содержит `content`, `summary`, `tags`, `links` (связи с другими заметками) и `audioData` (base64).
- `Settings`: Глобальные настройки. Разделены на модули: `ocr`, `transcription`, `agent`, `split`.
- `AIProvider`: Перечисление поддерживаемых провайдеров (Gemini, Ollama, LM Studio, OpenRouter).

## 3. Модуль ИИ (aiAdapter.ts)
Это ядро системы, которое абстрагирует работу с разными API:
- **Adapter Pattern**: Для каждого провайдера создан свой адаптер, который приводит ответ к единому формату.
- **Retry Logic**: Функция `withRetry` автоматически повторяет запросы при сбоях сети.
- **Caching**: Результаты анализа текста кэшируются в памяти для экономии токенов.
- **Metrics**: Система отслеживает задержку (latency) и количество успешных/неудачных запросов.

## 4. Контекст приложения (NotesContext.tsx)
Центральное хранилище состояния (React Context):
- **Оркестрация**: Управляет загрузкой данных, сохранением, фильтрацией и логами.
- **Telegram Sync**: Реализует опрос (polling) Telegram Bot API. Обрабатывает входящие `photo`, `voice` и `text`.
- **Background Tasks**: Автоматически запускает индексацию и бэкапы.

## 5. Основные функции
### Smart Text Splitter
Логика в `NotesContext.tsx` (`processLargeText`):
1. Текст разбивается на чанки по `splitChunkSize`.
2. Каждый чанк отправляется в ИИ для генерации заголовка и краткого описания.
3. Создаются связанные заметки.

### Telegram Bridge
1. Бот получает сообщение.
2. Приложение запрашивает обновления через `getUpdates`.
3. Если есть медиа (фото/голос), приложение скачивает файл через `getFile` и проксирует его.
4. Выполняется OCR (для фото) или STT (для голоса) через выбранный в настройках модуль.

### Neural Agent
Специальный промпт в `aiAdapter.ts` (`chatWithAgent`), который включает в себя контекст всей базы знаний (метаданные заметок, цели, логи) для ответов на системные вопросы.

## 6. Безопасность
- API ключи хранятся только в локальном хранилище браузера.
- При экспорте данных в JSON ключи включаются в бэкап (будьте осторожны при передаче файла бэкапа).
- Рекомендуется использовать локальные модели (Ollama) для максимальной приватности.

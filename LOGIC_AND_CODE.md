# 🧠 ScreenMind2 Ultra: Техническая документация и Логика

ScreenMind2 Ultra — это высокопроизводительная локальная система управления знаниями (KMS), построенная на принципах "Second Brain" (Второго мозга) с глубокой интеграцией искусственного интеллекта.

## 🏗 Архитектура Системы

### 1. Слой Данных (Storage Layer)
*   **IndexedDB**: Все заметки, цели, настройки и профили хранятся локально в браузере пользователя с использованием библиотеки `idb-keyval`. Это обеспечивает приватность и работу без интернета (после загрузки ресурсов).
*   **JSZip**: Используется для экспорта всей базы знаний в формате Markdown ZIP.

### 2. Слой ИИ (AI Adapter Layer)
Система использует паттерн "Адаптер" (`utils/aiAdapter.ts`), который позволяет подключать разные провайдеры для разных задач:
*   **Gemini**: Основной движок для анализа и OCR.
*   **Ollama / LM Studio**: Локальные провайдеры для полной приватности.
*   **OpenRouter**: Универсальный шлюз к сотням моделей.

### 3. Контекстная Логика (NotesContext)
Центральный узел приложения (`contexts/NotesContext.tsx`), который управляет:
*   **Синхронизацией**: Автоматическое сохранение при каждом изменении.
*   **Индексацией**: Фоновый анализ новых заметок.
*   **Связями**: Поиск семантически похожих заметок на основе ключевых слов, извлеченных ИИ.

## 🎯 Логика работы Целей (Goals)

Цели в ScreenMind — это не просто список задач, а стратегические ориентиры.
1. **Создание**: Вы формулируете цель.
2. **Семантический поиск**: Система берет название и описание цели, разбивает их на ключевые слова и ищет совпадения во всей базе ваших заметок.
3. **Связывание**: В карточке цели отображаются все заметки, которые "приближают" вас к результату.
4. **Редактирование**: Теперь вы можете корректировать цели (кнопка карандаша), меняя их описание, что мгновенно обновляет список связанных знаний.

## 📲 Telegram Bridge: Подключение и Логика

### Как это работает технически:
Приложение использует **Telegram Bot API** в режиме `getUpdates`. 
1. Вы отправляете сообщение боту.
2. При нажатии "Синхронизировать" приложение запрашивает новые обновления с серверов Telegram.
3. Сообщения временно хранятся во входящих (`Telegram Inbox`).
4. При обработке:
    *   **Текст**: Сразу идет в ИИ-анализатор.
    *   **Фото**: Отправляется в OCR-движок для извлечения текста.
    *   **Голос**: Скачивается, транскрибируется через STT-модель и сохраняется вместе с аудио.

### Инструкция по установке бота:
1. Создайте бота через **@BotFather**.
2. Получите **Token**.
3. Вставьте Token в **Настройки (System Core)** приложения.
4. Отправьте любое сообщение боту и нажмите **"Синхронизировать"** в разделе Telegram приложения.
5. Подробная инструкция доступна в файле `TELEGRAM_SETUP.md`.

## 🛠 Установка и Запуск (Для разработчиков)

1. **Требования**: Node.js 18+.
2. **Установка**: `npm install`.
3. **Запуск**: `npm run dev`.
4. **Сборка**: `npm run build`.

## 🎨 Дизайн и UI
Приложение использует **Tailwind CSS** с кастомной темой:
*   **Glassmorphism**: Эффекты матового стекла для панелей.
*   **Bento Grid**: Сетка для отображения заметок.
*   **Motion**: Анимации переходов через `motion/react`.


# 🏗 Техническая архитектура ScreenMind2

## Core Logic
- **`NotesContext.tsx`**: Центральный узел управления состоянием. Реализует паттерн "Provider", обеспечивая доступ ко всем данным (заметки, цели, логи) из любой точки приложения.
- **`aiAdapter.ts`**: Универсальный мост LLM. Поддерживает Gemini SDK (Native), Ollama API и OpenAI-совместимые эндпоинты. Оптимизирован для мультимодальных задач (OCR, STT).

## Компоненты и Страницы
- **`NoteEditor.tsx`**: Основной интерфейс работы с контентом.
  - *Вертикальный поток:* Заголовок -> Контент -> Семантические связи (Related Notes).
  - *Сайдбар:* Метаданные (Категория, Теги) и Neural AI Assistant.
- **`NotesPage.tsx`**: Библиотека с двумя режимами отображения (Сетка/Список) и глобальной фильтрацией по тегам и категориям.
- **`TelegramPage.tsx`**: Входящий буфер данных. Реализует Long Polling для обработки сообщений из бота.

## Data Schema (IndexedDB)
- **Notes**: Метаданные ИИ (`summary`, `tags`, `isIndexed`), геометрия воркспейса, медиа-данные (Base64 аудио).
- **Settings**: Конфигурация провайдеров для 4 независимых модулей (Аналитика, OCR, Voice, Agent).

## UI/UX Принципы
- **4rem Spacing:** Стандарт скругления для основных блоков.
- **Semantic Mapping:** Автоматическое построение связей на основе пересечения тегов и анализа категорий.
- **Visual Feedback:** Анимированные переходы (Tailwind animate-in) для всех состояний загрузки и сохранения.
